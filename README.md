# 兴仪全球禽业产业链情报中心｜静态网页版本

这是一个无需登录、可直接浏览的静态网站。使用原生 HTML、CSS、JavaScript 编写，无需安装程序依赖，也不需要先购买独立服务器。

## 如何预览
1. 解压压缩包。
2. 双击打开 `index.html`，即可在浏览器中浏览。
3. 也可以将整个文件夹上传到任意支持静态网站托管的平台。上传时请保持 `assets` 文件夹与 `index.html` 的相对位置不变。

## 当前包含
- 首页及五大情报板块导航
- 全球行情展示区域
- 38个目标国家搜索与选择交互
- 客户洞察、同行洞察、展会信息、法规准入内容入口
- 手机与电脑自适应布局

## 当前版本边界
- 页面中的地图、指标和行情状态是界面示意，不是真实实时数据。
- 当前没有自动新闻采集、AI分析、定时任务或数据库。页面中提及的每日 07:30 是规划中的更新节奏，不代表该功能已经运行。
- 联系方式尚未配置，因此没有可用的在线联系提交功能。
- 英文辅助页面尚未完成。

## 正式发布前只需补充
1. 公司确认的域名（可后续注册）。
2. 公司正式商务邮箱、电话及品牌 Logo（如有）。
3. 需要公开展示的真实资讯内容及来源。

## 发布方式建议
先使用静态网站托管服务发布，无需自行维护复杂服务器。绑定域名和启用 HTTPS 后即可通过网址公开访问。若未来需要自动更新资讯，再单独增加数据接口或后台，不影响当前网页继续使用。
